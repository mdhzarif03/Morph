# Code of Conduct

This project follows the spirit of the Contributor Covenant 2.1.

We commit to a harassment-free experience for everyone. Expected: respectful, constructive communication; accepting feedback gracefully; focusing on what is best for the project. Not acceptable: harassment, discrimination, personal attacks, doxxing, sexualised language or imagery, or other conduct that would reasonably be considered inappropriate in a professional setting.

Maintainers may remove comments, commits or contributions that violate this code and may ban repeat offenders. Report concerns privately to the maintainers using the contact method listed in SECURITY.md once the repository is published (add a dedicated conduct contact before going public).

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

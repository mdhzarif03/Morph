# Changelog

## 0.2.0

- New: merge PDFs and split/extract pages, with a thumbnail preview of every page before you run it.
- New: light, dark and system theme (Settings, Appearance).
- New: images (including WebP) can be converted to PDF; animated images can be exported as a ZIP of frames.
- Fixed: the popup now returns to the main page after you close and reopen it, including after a finished conversion.
- Changed: the global shortcut can be typed in Settings, and recording keeps the popup open when the Windows input-language switcher steals focus.
- Known: bookmarks and form fields are not carried into merged or split PDFs. Windows behaviour is not yet tested on a clean machine; the installer is unsigned.

## 0.1.0

First public build: image, document, PDF, audio and video conversion with a global shortcut popup.

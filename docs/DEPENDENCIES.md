# Dependencies and licences

Morph itself is MIT. It uses the following components. **This is engineering documentation, not legal advice.**

## Bundled with the app (npm)

See [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md) (generated by `npm run licenses`). Notable: Electron (MIT), React (MIT), Sharp (Apache-2.0) with libvips (LGPL-3.0-or-later).

## FFmpeg / FFprobe

`ffmpeg-static` and `@ffprobe-installer/ffprobe` are optional npm dependencies that download/ship prebuilt binaries. As reported by the installed packages, `ffmpeg-static` is **GPL-3.0-or-later** and the Linux ffprobe binary package is **GPL-3.0**. If you ship an installer containing GPL FFmpeg builds, you must comply with the GPL for that binary (provide source or an offer, licence text) even though Morph's own code is MIT, and it is a separate program launched as a child process. Alternatives: bundle an LGPL FFmpeg build in `vendor/ffmpeg/`, or ship without FFmpeg and let users install it. Check the exact builds you ship; the Windows binaries may differ from those inspected here.

## PDF rendering: PDFium (`@hyzyla/pdfium`)

The wrapper is MIT; it ships a WebAssembly build of Google's PDFium (BSD-3-Clause / Apache-2.0, see the package). It is bundled, nothing is installed on the user's computer.

## PDF merge and split: pdf-lib

`pdf-lib` (MIT) copies pages between PDF files. It is bundled; nothing is installed on the user's computer.

## Document conversion

- DOCX and ODT are read by Morph's own readers (`fast-xml-parser` MIT, `yauzl` MIT) and laid out by Electron's Chromium; `word-extractor` (MIT) reads legacy DOC as text.
- The generated HTML is laid out into a PDF by Electron's built-in Chromium (BSD-3-Clause and the licences listed in Electron's `LICENSES.chromium.html`, which the installer includes).

## Policy

Morph never downloads anything at run time. Everything it needs is inside the installer.
